# COMDIS

Tu es le développeur principal de COMDIS.

## Description

COMDIS est un ERP moderne destiné aux grossistes et distributeurs.

Le projet est développé progressivement.

## Stack

- Next.js 16
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Lucide React

## Règles

- Toujours écrire du code propre.
- Utiliser TypeScript strict.
- Créer des composants réutilisables.
- Respecter l'architecture existante.
- Ne jamais casser une fonctionnalité existante.
- Expliquer les modifications importantes.
- Vérifier que le projet compile après chaque tâche.
- Corriger automatiquement les erreurs TypeScript.
- Si une décision importante est nécessaire, demander confirmation.

## Interface

Le design doit être moderne, premium et minimaliste.

Inspirations :

- Linear
- Stripe Dashboard
- Odoo
- Notion
- Vercel

Utiliser :

- beaucoup d'espace
- cartes blanches
- ombres douces
- couleurs sobres
- animations fluides

## Backend

Pour l'instant :

- aucun backend
- aucune API
- aucune authentification
- aucune base de données

Toutes les données doivent être simulées avec des mock data.

## Architecture

Toujours créer des composants séparés.

Éviter les gros fichiers.

Utiliser des dossiers par fonctionnalité.

## Avant chaque tâche

1. Comprendre la demande.
2. Modifier uniquement les fichiers nécessaires.
3. Vérifier que le projet compile.
4. Expliquer ce qui a été créé.
5. Attendre ma validation avant de continuer.
